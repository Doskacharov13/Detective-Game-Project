1. Keep this Database folder in the project root, so the file is res://Database/detective_game.db
2. Install the godot-sqlite add-on: AssetLib tab at the top of the editor -> search "godot-sqlite" -> Download -> Install -> restart Godot.
3. Project -> Project Settings -> Globals (or "Autoload") tab:
   Path = res://Scripts/Database/game_db.gd   Name = GameDB   -> Add
4. Run the game (F5). The Output panel at the bottom should print: "Database opened. Items found: 6"
5. Use it from any script, for example:
   var item = GameDB.get_item(1)
   print(item["name"])                       # Old Storage Key
   var icon = load(item["icon_file"])        # the picture for the slot
6. Exporting the game: Project -> Export -> Resources tab -> "Filters to export non-resource files" -> write: *.db
